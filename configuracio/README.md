# Configuració tècnica del laboratori

Aquest directori està reservat als fitxers tècnics que es crearien durant l'execució del projecte. En aquesta pràctica només es planifica el treball; no s'inclouen contrasenyes, tokens, claus privades ni configuracions reals de màquines.

La futura configuració haurà de documentar, com a mínim:
- sistema servidor i adreçament IP del laboratori;
- paràmetres d'OpenSSH i usuaris autoritzats;
- política del tallafoc limitada a la xarxa de proves;
- proves de connexió acceptada i rebutjada;
- procediment de recuperació si es perd l'accés.
